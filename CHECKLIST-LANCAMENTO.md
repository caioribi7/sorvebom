# Checklist de Lançamento e Garantia — MCode

Execute esta verificação antes de entregar o site para o cliente e coletar o aceite formal:

### 1. Testes de Responsividade e Telas
- [ ] Visualização testada em Mobile Pequeno (320px - 375px)
- [ ] Visualização testada em Mobile Padrão (390px - 414px)
- [ ] Visualização testada em Tablet (768px - 1024px)
- [ ] Visualização testada em Desktop (1280px - 1920px)
- [ ] Menu móvel abre e fecha perfeitamente (incluindo fechar ao clicar no link ou tecla Esc)

### 2. Conversão e Links Diretos
- [ ] Todos os botões de WhatsApp abrem a conversa correta com o código do país (`55`) e DDD.
- [ ] A mensagem personalizada do WhatsApp está clara e sem erros de digitação.
- [ ] Link do Instagram direciona para o perfil oficial correto.
- [ ] Link de telefone direto (`tel:+55...`) dispara discagem imediata em smartphones.
- [ ] Link de localização abre a rota no Google Maps.

### 3. SEO, Metadados e Performance
- [ ] `<title>` e `<meta name="description">` preenchidos com as palavras-chave do cliente.
- [ ] Imagem de compartilhamento social (Open Graph) configurada (`og:image` de 1200x630px).
- [ ] Teste de pré-visualização no WhatsApp e Telegram (imagem e título corretos).
- [ ] Favicon exibindo na aba do navegador.
- [ ] Todas as imagens comprimidas em formato moderno (WebP ou SVG leve) com `alt` preenchido.
- [ ] Teste no Google PageSpeed Insights / Lighthouse (alvo: 90+ em Performance e SEO).

### 4. Domínio e Segurança
- [ ] Domínio registrado e apontado corretamente (sem erro de propagação).
- [ ] Certificado SSL ativo (cadeado verde / HTTPS forçado).
- [ ] Redirecionamento configurado de `dominio.com.br` para `www.dominio.com.br` (ou vice-versa).

### 5. Finalização Contratual
- [ ] Enviar link final de validação ao cliente.
- [ ] Coletar aceite formal (por escrito / WhatsApp ou assinatura).
- [ ] Registrar a data de início e término dos 3 meses de assistência técnica gratuita.
- [ ] Configurar lembrete no financeiro para o vencimento mensal do domínio (R$ 60,00).
